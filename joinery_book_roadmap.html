First Principles

从不可替代的事实倒推工作

01 · 物理结果是最高层证据

渲染只能证明模型可见，网格检查只能证明文件可用；只有真实打印、装配与测量能支持配合建议。

02 · 最小闭环优先于内容数量

一个案例完整走通“理解 → 下载 → 打印 → 装配 → 记录”，比十个只有正文的案例更接近产品价值。

03 · 单一来源，多种交付

参数化 CAD 是几何事实源；STEP、STL、GLB、爆炸图和书稿图都从版本化资产派生，避免互相漂移。

04 · Gate 由证据开启

阶段不按日期或页面数量完成。只有可下载、可复现、可观察的数据通过验收，才进入扩张与出版。

PHASE 1 · BLOCKING GATE

关闭首轮物理证据闭环

当前唯一关键路径：先得到本机 fit map，再验证它能否迁移到真实直榫几何。两套试件已经打印排版完毕，正在机器上跑。

按顺序执行
  1. ✓ 由参数化源生成直榫 C sweep（v0.1，C = 0.20 / 0.30 / 0.40 / 0.50 mm）
  2. 进行中 · 打印 Clearance Kit v0.1 与直榫 C sweep 排版
  3. 记录机器、材料、切片参数与四档实测
  4. 选择“压入 / 顺滑 / 滑动”对应的 C，不追求单一最佳值
  5. 比较测试块与真实榫卯的趋势是否一致
  6. 记录失败、照片与结论边界
产出
  • ✓ 直榫 C sweep 打印排版 STL v0.1
  • ✓ 装配 / 爆炸动画 GLB + 爆炸渲染
  • 首份完整 print log
  • 本机 / 材料 / 方向条件下的 fit map
  • “测试块 → 结构件”迁移结论
Gate A 证据
  • 四档均有装配结果和实测尺寸
  • 打印条件足够让他人复现
  • 直榫至少一档可完成装配
  • 建议值明确限定适用条件
2
PHASE 2

三个完整资产包 + 公开 MVP

Gate A 通过后，才把已验证的方法复制到燕尾与楔钉榫，并开放给陌生用户。

任务
  • 为直榫、燕尾、楔钉榫维护参数化源
  • 从同一版本导出 STEP / STL / GLB
  • 网页接入真实 3D 旋转、缩放与装配状态（直榫已接入，燕尾 / 楔钉榫待补）
  • 每个榫卯至少完成一轮真实打印
  • 补齐打印方向、装配、失败与尺度参照照片
  • 公开部署并记录下载与反馈
产出
  • 3 个可追溯榫卯资产包
  • Clearance Test Kit v1.0
  • 网页电子书 MVP v0.4
  • 真实失败案例与反馈入口
Gate B 证据
  • 陌生用户可独立下载并复现至少 2 个案例
  • 网页模型版本与下载文件一致
  • 手机、桌面与下载链路无阻断
  • 至少 5 位外部用户完成任务测试
3
PHASE 3

复制到 10 个榫卯 + 第一个作品

只在模板被真实用户证明可复用后扩张；先到 10 个并组合成一个物件，再决定是否继续增加。

任务
  • 按机械约束建立分类与学习顺序
  • 每次只增加一个新机制，累计到 10 个
  • 补充方向、材料或榫长等对照实验
  • 制作一个由已学榫卯组成的支架 / 小凳 / 小盒
  • 统计制作成本、复现率和内容维护时间
产出
  • 10 个完整榫卯资产包
  • 3 个可复现实验
  • 第一个完整作品教程
  • 网页图鉴 v0.6
Gate C 证据
  • 新增案例不需要改变资产契约
  • 至少一个作品由多个前置榫卯组合
  • 用户能从单结构自然进入完整作品
  • 维护成本允许继续扩充
4
PHASE 4

出版样章 / 纸书 Proposal

只有当网页的结构和读者反馈成立后，才把成熟内容抽取成纸书样章。

任务
  • 从网页选出 3–5 个最强案例
  • 设计 16–32 页样章
  • 整理目标读者、竞品、差异点、目录和市场数据
  • 整理网页访问、下载、打印反馈等验证数据
  • 形成出版社投稿版本 proposal
  • 定向联系机械工业 / 电子工业 / 建筑类出版社编辑
产出
  • 16–32 页出版样章 PDF
  • 完整选题策划书
  • 候选出版社与编辑列表
  • 市场验证数据摘要
验收标准
  • 编辑 5 分钟内能理解本书差异点
  • 样章不是网页截图，而是适配纸张的重新排版
  • 至少具备真实用户数据或打印反馈作为支撑
5
PHASE 5

实体书制作与数字内容共生

实体书不是终点，而是“纸书 + 网页 + 模型下载 + 更新内容”的组合产品。

任务
  • 冻结纸书目录和章节顺序
  • 完成 30–50 个高质量案例，而不是追求“大全”
  • 统一摄影、线稿、爆炸图和参数表风格
  • 设计 QR 码：连接到网页动画 / STL / STEP
  • 完成编辑、审校、版权和印刷协作
  • 同步维护网页版本，不让数字内容停更
产出
  • 实体书 v1.0
  • 对应数字模型库
  • 网页正式版 v1.0
  • 可继续扩展的作品 / 实验体系
验收标准
  • 纸书脱离网页也可独立阅读
  • 网页能补充纸书无法表达的动态内容
  • 书中所有下载链接长期可维护
关键路径：只有证据能解锁下一步
Clearance 实打→直榫迁移验证→3 个完整资产包→外部复现→扩到 10 个→出版样章

资产契约、记录工具和网格检查可与实打并行；燕尾、楔钉榫批量建模与更多正文不能绕过物理 Gate。

Workstreams

长期并行的 7 条工作流

01 · CONTENT

内容研究

名称、历史、机械原理、适用场景、分类、解释文案、参考资料。
02 · CAD

参数化建模

统一尺寸基准、可调 clearance、STEP/STL/GLB 输出、版本管理。
03 · PRINT

打印验证

材料、方向、层高、支撑、公差、失败案例、可重复性。
04 · VISUAL

视觉与摄影

线稿、爆炸图、剖面、CAD render、实物摄影、未来纸书版式。
05 · WEB

网页产品

信息架构、3D 交互、下载、移动端、部署、基础统计。
06 · VALIDATION

用户验证

访问、收藏、模型下载、打印反馈、最受欢迎结构、问题收集。
07 · PUBLISHING

出版准备

样章、目录、选题策划、竞品分析、出版社沟通、印刷与版权。
Decision Gates

阶段由什么证据开启？

Gate A · 物理基线成立

Clearance 四档记录完整；直榫至少一档装配成功；结果明确绑定机器、材料、方向与切片参数。

Gate B · 陌生用户可复现

3 个资产包可追溯；至少 5 位外部用户完成理解与下载任务，其中至少 2 人独立打印成功。

Gate C · 模板值得扩张

新增案例无需改变资产契约；已有下载、打印、失败与维护成本数据，证明扩到 10 个不会放大返工。

Gate D · 纸书有独立价值

网页已经验证学习路径；样章在纸面测试中仍能独立理解；版权、更新与长期下载维护责任清晰。
