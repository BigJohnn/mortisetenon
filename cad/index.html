先把“能打印”
定义清楚。

以下尺寸是教学样件的首轮工程起点，不是传统家具行业标准。目标是让三个结构在 0.4 mm 喷嘴 / 0.20 mm 层高的常见 FFF 条件下快速试错，并把所有配合量参数化。

统一定义 Clearance C = 母件有效尺寸 − 公件有效尺寸（总差值）。对称配合时，单侧理论间隙 = C/2。首轮从 C = 0.20 mm 起步，但不把它写成“正确答案”。

02 · Dovetail

燕尾：只隔离“几何自锁”

v0.1 采用滑入式燕尾教学模型，不是对抽屉多尾燕尾的历史复刻。这样能让读者只比较直壁与斜壁带来的运动约束。

第一轮至少比较两种打印方向。不要只记录“能不能装”，还要看斜面表面质量与破坏位置。
