01 · Principle

它限制的不是“力”，而是运动。

燕尾的侧壁向外张开。若试图从非开口方向拉出，宽端会撞上卯口；原本简单的拉出，转而需要压坏、变形或让接触面滑开。几何先规定了哪些运动不可能，摩擦才在其后影响手感。

02 · Read the joint

先看它要求怎样装，再决定要不要打印。

上面的模型不承担“炫技动画”的任务。旋转模型，或拖动拆装进度，回答三个实际问题即可。

从哪里进入？
两件只能沿燕尾开口方向滑入；侧向硬压不是它设计允许的装配路径。
哪里拦住拉出？
宽端与卯口的斜侧壁相互抵住。这是它对抗拔出的来源。
模型没告诉我什么？
摩擦、层纹、象脚、材料弹性和徒手所需的力，必须由实物来回答。
阅读边界：两个模型状态都来自同一冻结的 Onshape v0.2；它们验证几何位置与分开后的关系，不能替代真实打印件的公差或手感验证。
03 · Geometry

这不是抽屉燕尾，而是一个只讲自锁的剖面样件。

为了让读者把注意力放在“斜壁如何限制运动”上，v0.2 暂时拿掉了多尾、胶合面积和长木料变形这些真实木工问题，只保留一根滑入式公榫和一个同轮廓母槽。

项目v0.2 当前值为什么这样写
结构变体滑入式燕尾教学模型装配方向唯一，便于和直榫比较“直壁 vs 斜壁”
配合间隙C = 0.20 mm / 侧壁配合；顶部另留 0.20 mm这是首轮实验起点，不是推荐值
内部让位socket-root relief = 0.40 mm避免内角和打印圆角在槽根先顶死，把问题留给斜壁配合
事实源Onshape version dovetail v0.2版本已冻结；页面链接指向 /v/，不指向会漂移的工作区
当前发布状态DRAFT没有 STEP / STL / release manifest 条目，也没有完整 print log
本章现在可以写清楚的结论
  • 燕尾的抗拔来自运动被几何挡住，不来自“摩擦更大”这个单独因素。
  • 滑入方向必须在内容里明确；如果读者从错误方向用力，失败不代表结构不可打印。
  • 斜面同时是力学面和打印面，方向选择会同时改变表面质量、层间受力和装配手感。
本章现在不能写的结论：不能说 0.20 mm 是燕尾推荐 clearance，不能把“徒手能合拢”升级为 PRINT_VERIFIED，也不能提供 STL 让读者误以为这一版已经完成发布验证。

05 · Reproduce with intent

下一轮不是“再打一件”，而是找出偏紧来自哪里。

若你要复刻，请只改变一个会影响配合的变量，并让每次打印都留下可比较的证据。燕尾最容易把问题混在一起：入口毛刺、斜面层纹、槽根内角和真实 clearance，都会表现成“推不动”。

先量尺寸
颈部宽、外端宽、母槽入口、槽底宽和顶部间隙。没有尺寸，就无法区分设计 C 与打印误差。
记录方向
写下哪一面朝下、斜壁是层叠出来还是沿喷嘴路径扫出来；这直接影响斜面手感。
只动一个变量
下一版优先比较 C = 0.20 / 0.30 / 0.40 mm，或固定 C 后只换打印方向。
推荐的下一轮记录顺序
  • 先用当前 v0.2 再打一件，补齐材料、方向、切片版本、墙数、填充和照片。
  • 量公榫两端宽度与母槽对应宽度，计算实际 C 是否接近 0.20 mm。
  • 给插入力和晃动打分，记录是入口先卡、斜壁全程紧，还是最后槽根顶住。
  • 如果仍偏紧，再导出 C = 0.30 mm 版本；若 0.30 变成顺滑，才有资格写成下一轮假设。

06 · Context

历史只讲到足够理解。

“燕尾”是一个跨家具、木作和建筑都能遇到的几何家族。不同语境的具体形态并不完全相同；本页只讨论这一个滑入式教学变体，不把抽屉燕尾、梁柱燕尾等混成一种。
