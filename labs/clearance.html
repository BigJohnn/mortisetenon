装配手感不是 CAD 里一个孤立的数字。尺寸、方向、几何、校准、切片设置与材料都会改变结果。0.10–0.40 mm 是这次实验的四级刻度，不是放之四海皆准的答案。

01 · Definition

CAD 里的 C，不等于手里的缝。

本项目把 clearance C 定义为“母件有效宽度 − 公件有效宽度”的总差值。几何居中时，每侧理论间隙才是 C/2。

设计总间隙Cdesign = Wfemale,CAD − Wmale,CAD
打印后实际总间隙Cactual,x = Wfemale,x − Wmale,x
另一方向单独计算Cactual,y = Wfemale,y − Wmale,y

X 与 Y 必须分开。一个方榫只要在其中一个方向发生干涉，就可能装不进去；把两轴平均会藏掉真正的卡点。

设计值

你要求 CAD 留多少

这次是 0.10 / 0.20 / 0.30 / 0.40 mm。它只描述模型，不自动代表打印结果。

实测值

机器实际上打出多少

母孔可能偏小，公件可能偏大；入口象脚与层纹还会形成局部干涉。

配合手感

装起来发生什么

“压入”或“滑动”是结果分类，必须和尺寸、材料、方向与切片参数一起记录。

02 · Protocol v0.2

先固定变量，再从“量”走到“装”。

第一轮的价值不在于找到一个漂亮数字，而在于让第二个人按同样条件能重做一次。下面的顺序也避免试装先刮伤配合面，污染后面的尺寸记录。

  1. 01

    确认打印的是哪一版

    下载 Clearance Test Kit v0.1，保持 100% 缩放。记录 STL 的版本或 SHA-256，避免日志和几何对不上。

  2. 02

    按约定方向切片

    测试板平放；四个公件的方形底座贴床、12 × 12 mm 杆朝上。记录切片器、版本、墙数、填充和任何尺寸补偿。

  3. 03

    还在热床上时先标记

    v0.1 板件本身没有浮雕刻度。俯视打印排版、让四个公件位于板件远侧时，母孔从左到右是 C = 0.10 / 0.20 / 0.30 / 0.40 mm。取件前在 0.10 端做记号；四个公件也按同一顺序标为 A–D，并分别与同列母孔配对，首轮不要串换。

  4. 04

    先观察，再测量

    先拍整体方向照，记录翘曲、拉丝、接缝和象脚。不要先试装。公件在杆身中段量 X/Y；母孔用内测量爪在有效直壁段量 X/Y，避开顶部 0.6 mm 导入口。

  5. 05

    每个尺寸量三次

    保持同一测点与卡尺姿态，三次读数取中位数填表。先算 X、Y 两个 C actual，再开始装配。

  6. 06

    由松到紧试装

    从 0.40 mm 开始，再到 0.30、0.20、0.10 mm。沿同一方向压入，不扭转、不锤击；记录是否完整就位、装配力、能否徒手拆卸和卡点位置。

一次完整记录至少包含
  • 打印机、材料、喷嘴、层高、墙数、填充、缩放与方向
  • 四档各自的公件 X/Y、母孔 X/Y 与配合分类
  • 打印方向照、整体结果照，以及任何失败或损伤
  • 没有装上的档位也必须保留；失败不是空值

本版已知限制：四个公件几何相同，板件也没有刻度。标记必须在取件前完成。下一版 CAD 应把档位直接做进板件和公件，但这会形成新的资产版本，不能悄悄替换 v0.1。

03 · Read the result

先看顺序，再给每一档命名。

理想结果会随 C 增大而逐步变松。但“实际间隙为正”不保证一定能滑动：象脚、层纹、接缝、孔角圆化和配合长度仍可能在局部制造干涉。

JAMMED

卡死

无法完整就位，或继续施力会明显损伤试件。

PRESS-FIT

压入

全程需要明显外力，装好后主要靠摩擦保持。

SNUG

紧配

徒手能完整就位，有持续阻力，晃动不明显。

SLIDING

滑动

轻推可移动，也能徒手拆出，仍有方向控制。

LOOSE

松动

容易移动，并出现可感知的横向晃动。

看到的组合它更可能说明什么下一步
某一轴 C actual ≤ 0该方向已经是尺寸干涉，不必用手感替它找借口。检查公件偏大还是母孔偏小，并保留原始尺寸。
两轴 C actual > 0，但仍卡死局部象脚、接缝、层纹或测点没有覆盖真正卡点。观察擦痕与卡点；不要只增大 CAD 间隙后结束。
C 增大，结果稳定地变松这轮实验形成了可读的排序。在“压入 / 紧配 / 滑动”中按用途选起点，不选唯一冠军。
中间档比相邻档更紧单件波动、标记错误、翘曲或测量误差可能盖过设计步长。复核编号和尺寸；必要时重打，不强行画趋势线。
结论边界只有当四档都有尺寸、手感和照片，且打印条件完整时，才得到“这台机器 × 这批材料 × 这组设置 × 这个方向”的 fit map。它仍不是全局推荐值。
04 · Transfer

测试块是标尺，直榫才是结构。

Clearance Kit 与直榫共同拥有 C = 0.20 / 0.30 / 0.40 mm 三档。只在相同机器、材料、切片参数和相近时间条件下比较这三档；0.10 与 0.50 mm 只补各自边界，不参与一一配对。

同档同分类

本轮可以迁移

测试块在这组条件下能预测直榫的配合类别，但结论仍只限本轮条件。

顺序一致，整体错一档

可排序，不能直接套数值

测试块能告诉你“谁更紧”，结构长度、榫肩或打印方向却改变了绝对手感。

顺序也不一致

迁移失败

先查编号、尺寸、局部缺陷和测量方法；数据没有解释清楚前，不发布推荐 clearance。
