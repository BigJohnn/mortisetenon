## 三件与同尺度参数

2026-09-12 本地检查已通过：6 个有效单实体；6 个水密且绕向一致的零件网格；每套 49 + 97 个装配位置均无体积相交；四个越位负对照均发生预期干涉。已输出两套 STEP、逐件 STL、GLB 拆装预览及装合/拆分渲染。预览使用软件深度缓冲直接绘制检查网格，不再依赖 Blender。没有创建 `.FCStd` 参数历史文件，也没有完成云端编译。

长度 mm，角度 deg。Z=0 是面板下表面的承托基准；腿固定。X 沿牙条长度，Y 沿牙条厚度，Z 向上。

| 参数 | 本轮值 | 解释 |
| --- | ---: | --- |
| stock | 24 | 腿方截面 |
| legLength | 96 | 腿在 Z=0 以下的展示长度 |
| apronLength / apronThickness / apronHeight | 96 / 8 / 24 | 牙条基础外廓 |
| topWidth / topThickness | 40 / 16 | 面板宽 / 厚；长度沿用 96 |
| tenonWidth / tenonThickness / tenonHeight | 16 / 2 / 8 | 两个顶榫各自的宽 / 厚 / 高 |
| fit | 0.30 | 顶榫与卯孔 X、Y 方向的总间隙，各侧 0.15；非推荐值 |
| slotFit | 0.30 | 仅夹头槽的 Y 向总间隙；插肩不使用此字段 |
| endGap | 0.40 | 顶榫避底；插肩另用于槽底让位 |
| spread | 4 | 插肩牙头从下到上每侧展开量 |

两个顶榫中心在 Y=±10 mm。2 mm 的薄榫仅为数字结构起点，未验证打印强度；当前也没有入口倒角、象脚补偿、刀具圆角或应力释放。

## 接触面与教学简化

共同 IF-TOP：双顶榫限制面板横向运动，腿上肩面在 Z=0 承托面板；顶榫高 8，盲卯深 8.4，不应由榫端先顶住孔底。牙条顶面同样到达 Z=0，名义共面不代表打印后能同时接触。

夹头 IF-APRON：腿上开平行通槽，宽 8.3，槽底 Z=-24。8 mm 厚牙条沿 −Z 落入，槽底为水平 STOP 面；侧面为有间隙的导向面。原型中分开的牙条与牙头在本项目三件版中合并，未表现独立牙头、弧形装饰或正交第二根牙条。

插肩 IF-APRON：牙条中部与牙头合并成一实体，其 YZ 截面由底宽 8 向顶宽 16 展开，高 24。腿槽有对应的两斜面，斜度相对竖直约 9.4623°。两斜面是零名义法向间隙的 STOP 面；槽底再下让 0.4，避免底面抢先停止。**这是一种原创双斜肩教学变体**，不是对某件传统插肩榫的尺寸复制；零名义间隙不意味着 FDM 打印后能顺畅入位。

结构参照：[香港浸会大学 · 夹头榫](https://digital.lib.hkbu.edu.hk/mortise_tenon/structure.php?id=MTS-000033)、[插肩榫](https://digital.lib.hkbu.edu.hk/mortise_tenon/structure.php?id=MTS-000015&lang=en)。参照仅支持机制辨识；本表尺寸、双顶榫布置和教学牙头均由本项目设定，不归因于来源。

## 装配顺序与检查定义

1. 固定 Leg；Top 暂停在 +96，Apron 在 +48。
2. Apron 沿 −Z 从 +48 移到 0；Top 保持 +96。
3. Top 沿 −Z 从 +96 移到 0；Leg、Apron 不动。
4. 拆卸严格反向：先抬面板，再抬牙条。没有把同时移动三件当作实际装配步骤。

两种节点各检查三个有效单实体、六个零件的水密网格与一致绕向、解析体积、最终三对零件的相交体积。装配路径每 1 mm 采样，牙条 49 个位置、面板 97 个位置。负对照把移动件越过终点 0.5 mm，应与腿相交，以区分“确实有止挡”与“根本没有接触”。采样不是连续扫掠证明，也不是动力学、摩擦或有限元分析。

## 可复现命令

在具有 `cadquery==2.8.0`、`trimesh==5.1.0`、`numpy`、`Pillow` 的 Python 环境运行：

```sh
python tools/check_table_nodes_local.py
python tools/render_table_nodes_local.py
```

核对结果写入 `table-node-pair_local-check/report.json`，包括源代码 SHA-256、参数、体积、包围盒、网格哈希、路径采样与越位负对照。预览不得改标为 Onshape 导出。获准云端保存后，应从冻结版本重新导出并与本地解析体积及包围盒交叉核验，再更新本记录。
